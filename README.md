# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, revenue trends, product performance, and regional sales.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Total Revenue KPI
- Total Orders KPI
- Total Units Sold KPI
- Average Order Value KPI
- Product-wise Revenue Analysis
- Monthly Revenue Trend
- Interactive Region, Category, and Date slicers

## Business Objective
To understand sales performance, identify high-performing products and periods, and support data-driven business decisions.

## Key Insights
Add verified insights from the completed dashboard, including the top-performing product, highest-revenue month, and best-performing region.

## Files Included
- Power BI dashboard (`.pbix`)
- Dashboard screenshot (`.png`)

## Conclusion
This project demonstrates data cleaning, KPI development, data visualization, and interactive business reporting using Microsoft Power BI.
